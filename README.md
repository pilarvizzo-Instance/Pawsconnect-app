# PawsConnect AI Feature Suite — Homework 1

PawsConnect is a two-sided platform connecting animal shelters with prospective adopters. This demo showcases an AI feature suite in **Cached Demo Mode**.

## Features

- **Part B — Photo-to-Profile Listing Generator:** Uses multimodal vision to generate an adoption profile from an animal photo.
- **Part C1 — Adoption Inquiry Triage:** Classifies adoption inquiries into a queue using few-shot examples.
- **Part C2 — Adoption Counselor Persona:** Uses an LLM-as-judge guardrail following the DoorDash pattern.
- **Part C3 — Adopter-Pet Match Explainer:** Explains potential matches using self-consistency voting.
- **Part D — Shelter Intake Medical & Quarantine Sentinel:** Flags medical and quarantine considerations during shelter intake.
